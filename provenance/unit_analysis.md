# Unit ENSO analysis

We fit 8,738 independent unit–crop–season series across 677 administrative units and 288 panels. The inventory covers all crops in the supplied files. Eligibility requires 20 complete positive-yield years and at least five exposures on each side of zero Niño 3.4. We retain all exclusions in series_inventory.csv. Crop forms and component totals overlap, so series counts are not counts of independent outcomes.

We estimate each unit’s intercept, time trend, and linear Niño 3.4 response jointly. We examine quadratic curvature and a hinge at zero, with held-out five-year blocks, one adjacent embargo year on each side, and two block placements anchored at 1980 and 1982. A nonlinear candidate beats both linear ENSO and trend-only predictions in both layouts using the same nonlinear form. We repeat the first layout with quadratic time trends as an additional check. We compute no uncertainty intervals, resampling estimates, or significance tests. Candidate selection across many comparisons may produce chance findings.

ENSO_unit_atlas.html is self-contained. We can select all country–crop–season groups, inspect maps and unit response curves, and export the maps as SVG. Gray includes units with insufficient data and units without the selected crop. A neutral-to-+1°C yield response is expressed as 100[exp(beta)−1]; variance explained is partial R² after the time trend. Nonlinear gain maps show the smaller gain across the two layouts, in percent reduction of MSE relative to the linear ENSO model. Complete values remain in the table even when map colors saturate.

We use established windows for the earlier panels and the supplied calendar for other seasonal records. Rice components and processing forms inherit the corresponding paddy window. Annual records use January–December, with Indian Whole Year assigned to the following year. Each result records its calendar assumption. We apply the verified East Java 2017 rice correction only in derived calculations. We preserve other source yields and flag extreme values for inspection. No automatic outlier exclusion is applied.

The archive preserves the original directory structure under ENSO_unit_analysis/1_ag. The analysis lives in analysis_20260924/unit_analysis. With Python dependencies from analysis_20260924/requirements.txt installed, run python analyze_units.py, python verify_units.py, python build_atlas.py, and python write_report.py from the unit_analysis directory. build_atlas.py writes the local atlas and optionally copies it into the original workspace outputs if that directory exists. Compile the supplement using pdflatex ENSO_unit_response_supplement.tex twice. Source input tables and geometries are included, together with the frozen index and season calendar. No network access is required to reproduce the calculations.

unit_results.csv contains coefficients, sensitivities, partial R², validation scores, and screening flags. observations.csv.gz contains the complete analysis observations. heldout_predictions.csv.gz stores every prediction by validation layout. panel_inventory.csv and series_inventory.csv cover eligible and excluded data. country_summary.csv tabulates screening counts. verified_correction.json records the BPS cell correction. verification.json records independent numerical checks. Source hashes establish that supplied statistics were unchanged. Vector figures and PNG previews cover the original 21 panels; all 288 fitted panels are mapped in the interactive atlas.

## September 25 scenario and observation views

The atlas now opens with a +3°C event-peak scenario. We assume the monthly Niño 3.4 shape of 1997–98, rescale the profile by 3 divided by its 1997 monthly maximum, and align the event with the selected peak year (2026 by default). Each panel uses its existing planting-to-harvest window and the selected crop reporting year. Users can inspect the monthly path and switch to a direct crop-season mean of +3°C. An event peak alone does not specify crop exposure; the historical profile is an assumption. Changes in reporting year also retain the original calendar uncertainties.

Scenario responses relative to neutral ENSO are 100[exp(βx)−1] for the linear model, 100[exp(βx+δx²)−1] for the quadratic model, and 100[exp(βwarm x)−1] or 100[exp(βcold x)−1] for the hinge model. The three scenario maps, unit table, response curves, and downloadable CSV use the same crop-season exposure x. The diagnostic maps remain available. We flag extrapolation outside each unit’s observed exposure range. All three models remain visible regardless of the nonlinear candidate screen; these point estimates carry no uncertainty intervals and are not calibrated yield forecasts.

The observation view contains every fitted year from observations.csv.gz. Users can select a model and show raw yield in t/ha or 100[exp(log yield − model intercept − model time trend)−1]. The adjusted scatter therefore matches the selected model’s neutral-ENSO baseline. The raw scatter curve is evaluated at the mean observed reporting year. The time-series plots show observed yields, in-sample model predictions, and an aligned plot of the crop-season Niño 3.4 exposure. Hover text records the year and values. Annual gaps are not joined.

atlas_observations.py embeds these observations and reconstructs the intercepts and trends by least squares, checking the ENSO coefficients against every saved result to within 1e−6. Running that script refreshes the HTML from the existing embedded geometry, template, and atlas_explorer.js without rerunning validation or drawing static figures. build_atlas.py also includes the new payload and interface, so a full rebuild preserves these additions.

export_scenarios.py writes scenario_3C_results.csv for all 8,738 fitted series: the +3°C scaled event with crop reporting years 2026 and 2027, and a direct +3°C crop-season average. The 26,214 rows retain each panel’s calendar note and extrapolation flag. The HTML download exports the currently selected panel and scenario controls.

## Atlas layout and coverage, September 25

Selectors now list only country–crop–season panels with fitted data and show result counts. Crop and season selections persist when available in the next country. The coverage drawer lists source series and exclusions across countries for the selected crop. Wheat has 347 fitted series: 326 Indian Rabi units, 16 Bangladeshi units, and 5 Korean units. All 38 Japanese wheat series fall below 20 complete positive-yield years (maximum 18). India's Kharif, Summer, Whole Year, and Winter wheat panels also have no qualifying series. The eligibility threshold is unchanged.

Each map has a labeled SVG color bar above the geography. Scenario maps share an adjustable symmetric scale (±20% by default), with counts of saturated units. The single yield-versus-Niño 3.4 plot contains observations, the selected model, the scenario marker, and dashed extrapolations. Raw and trend-adjusted views remain available. The aligned yield and ENSO time series remain below the unit selection. Fit diagnostics, monthly scenario shape, and the full unit table are collapsible.
